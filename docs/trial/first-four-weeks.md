# First four-week trial

## Hypothesis

EMOS becomes the manager's default daily view and reduces time spent remembering, inspecting, and chasing incident follow-up by 75%: from the 120-minute baseline to at most 30 minutes per working day.

## Daily capture

| Date | EMOS active minutes | External-system minutes (self-check) | Resolved cases | Cases dispositioned | Within 24 working hours | Notes / missing capability |
| ---- | ------------------: | -----------------------------------: | -------------: | ------------------: | ----------------------: | -------------------------- |
|      |                     |                                      |                |                     |                         |                            |

EMOS calculates only its own visible, focused interaction time. Record time spent directly in JSM, Datadog, GitHub, and Jira once per day; EMOS does not monitor those applications.

## Weekly review

At the end of each week, record:

- average total manager minutes/day = EMOS time + external-system self-check;
- disposition coverage = resolved standalone alerts with a disposition / resolved standalone alerts;
- percentage dispositioned within 24 working hours;
- duplicate Jira issues, missed alerts, incorrect evidence, and recommendations rejected;
- whether Today was the first place checked each working day;
- the single largest remaining source of remembering or chasing.

## Decision after week four

Continue or expand only if the workflow is trusted and total manager time trends toward 30 minutes/day without hidden employee surveillance or unsafe automation. Choose one next investment from measured evidence: remaining dispositions, confirmed-incident grouping, or revision of this slice. Do not add employee growth features during this trial.
